### Things I built

**Aion (灵汐)** · [aion.7caifei.com](https://aion.7caifei.com) · macOS · Swift
A background automation assistant that quits genuinely idle apps — and refuses to touch anything downloading, playing, recording, or on a call. Free/pro tiers, licensing, iCloud sync, release pipeline. macOS 14+, Intel + Apple Silicon.

**[AI Memory Hub](https://github.com/monkey-sking/ai-memory-hub)** · Apache-2.0 · JavaScript
One shared memory and coordination layer for every AI coding tool you run. Claude Code, Codex, Gemini CLI, opencode — one ledger, one task board, no human message bus. *Not* another vector database; the hard part is coordination semantics.

**Currently dogfooding both daily** on a multi-agent workflow that runs on this machine.

### How I think about this work

- The interesting engineering is usually the **false positive**, not the feature. An automation that is 90% right is worse than no automation.
- Before "what does the model score", ask **"what does the player feel at second 30"**.
- AI product work fails in the **system around the model** — ownership, handoff, what counts as done.
